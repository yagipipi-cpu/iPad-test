# 五目並べ PWA 設計

iPad の Safari で動く、自分専用の CPU 対戦五目並べ。

## 決定事項

| 項目 | 決定内容 |
|---|---|
| 形態 | iPad Safari 向け PWA。自分専用 |
| 対戦相手 | CPU のみ |
| CPU の強さ | 盤面評価 + ミニマックス法（αβ枝刈り）。まず「勝てる手を打つ／四を止める」ルールで動かし、その後に読みを足す |
| CPU の考える時間 | 上限1秒。反復深化で時間切れ時点の最深結果を採用。Web Worker で計算 |
| ルール | 自由ルール（5つ以上で勝ち、禁じ手なし）。先手・後手を選択可 |
| 盤 | 15×15（定数 `BOARD_SIZE` で管理） |
| 石の置き方 | 1回目のタップで仮置き、同じマスをもう一度タップで確定。別のマスをタップすると仮置きが移動 |
| 待った | 回数無制限。自分の手と CPU の手を2手まとめて戻す。CPU 思考中は無効 |
| 保存 | 一手ごとに localStorage へ自動保存し、起動時に復元 |
| オフライン | ホーム画面に追加して使う。Service Worker でオフライン起動 |
| 公開 | リポジトリを public にし、GitHub Actions で GitHub Pages に公開 |
| 技術 | TypeScript + Vite、フレームワークなし、盤は SVG、`vite-plugin-pwa` |
| 画面の向き | 縦横両対応。盤は短辺に合わせた正方形。ボタンは縦向きなら下、横向きなら横 |
| 対局の流れ | 開始時に先手・後手・ランダムを選択（前回の選択を記憶）。CPU の最後の手に印。勝敗決定時は5連を強調し結果を表示、終局後も「待った」可。対局途中の新規開始は確認を出す。盤が埋まったら引き分け |
| テスト | ルール判定と CPU の重要判断は Vitest。画面操作は iPad 実機で確認 |
| 更新 | 新しい版があれば「更新」ボタンを表示。画面の隅に版番号（コミット短縮ID）を表示 |

## 実装上の判断

- ダブルタップ・ピンチでの拡大を無効化する
- CPU が先手のときの初手は天元（中央）
- 着手候補は既存の石から2マス以内に絞る

## 進め方

1. 2人で交互に打てる盤と勝敗判定、そのテスト
2. CPU（ルールベース → 読みの追加、Web Worker 化）
3. 待った・自動保存・対局の流れ
4. PWA 化・GitHub Pages 公開
