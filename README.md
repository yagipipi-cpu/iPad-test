# 数独

iPad の Safari で遊べる数独ゲーム（`index.html` 1ファイル、ビルド不要）。

- 難易度3段階、毎回自動生成（解は必ず一意）
- ミス表示・ヒント・元に戻す/やり直す・タイマー・一時停止
- 途中保存（ブラウザに自動保存）
- 外付けキーボード対応（数字 / 矢印 / Backspace / ⌘Z）

GitHub Pages を有効にし、Safari の共有メニューから「ホーム画面に追加」するとアプリ風に使えます。

# 筋トレタイマー

`workout.html`（1ファイル、ビルド不要）。iPad を横置き・縦置きどちらでも使えます。

- **インターバル**：準備 / ワーク / レスト / セット数 / ラウンド数 / ラウンド間休憩を設定。プリセット（タバタ・HIIT 40/20・サーキット・EMOM・筋トレ5セット・プランク）付き
- **セット休憩**：30秒〜3分のワンタップ休憩、±10秒、完了セット数を自動カウント
- **ストップウォッチ**：ラップ記録（最速・最遅を色分け）
- ビープ音・日本語音声カウント（3・2・1、半分、ラスト10秒）・画面スリープ防止
- 設定は自動保存。外付けキーボード対応（Space / ← → / L / R）
