# 数独

iPad の Safari で遊べる数独ゲーム（`index.html` 1ファイル、ビルド不要）。

- 難易度3段階、毎回自動生成（解は必ず一意）
- ミス表示・ヒント・元に戻す/やり直す・タイマー・一時停止
- 途中保存（ブラウザに自動保存）
- 外付けキーボード対応（数字 / 矢印 / Backspace / ⌘Z）

GitHub Pages を有効にし、Safari の共有メニューから「ホーム画面に追加」するとアプリ風に使えます。

# 筋トレ時計2

`timer.html`（1ファイル、ビルド不要）。スタートからの経過時間を分:秒で表示するストップウォッチ。

- 外周のリングが1分で1周（57〜59秒はオレンジ、00秒で赤くフラッシュ）
- 毎秒クリック音、57・58・59秒に 440Hz「ピッ」、00秒に 880Hz「ポーン」（NHK 時報と同じ音程）
- スタート／一時停止（再開）／ストップ（00:00 に戻す）
- 毎秒の音・時報の ON/OFF、音量（ブラウザに保存）
- 計測中は画面スリープを防止（対応ブラウザのみ）、iOS 17+ では消音スイッチ中も鳴る
- 外付けキーボード: スペースでスタート／一時停止、Esc でストップ
